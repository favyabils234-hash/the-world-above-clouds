# The World Above the Clouds

An original, illustrated parallax landscape made with plain HTML, CSS, JavaScript and inline SVG. No dependencies or external images are required.

## Run locally

Open index.html in a browser, or serve this folder with a static file server such as python3 -m http.server 8000.

## GitHub Pages

This repository is configured for a project site. Enable **Settings → Pages → Deploy from a branch**, select **main** and **/(root)**, and save. Once the first deployment finishes, the site will be at https://favyabils234-hash.github.io/the-world-above-clouds/.

All asset paths are relative. The landscape has a mobile crop and the scroll effect respects reduced-motion preferences.
